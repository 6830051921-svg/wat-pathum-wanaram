## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/`; there are no PRs to triage. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default role names, recorded as a `Status:` line in each issue. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
