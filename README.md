# วัดปทุมวนารามราชวรวิหาร

เว็บไซต์นำเสนอประวัติ ศิลปะ และสถานที่สำคัญของวัดปทุมวนารามราชวรวิหาร กรุงเทพมหานคร

**เปิดดูเว็บไซต์:** https://6830051921-svg.github.io/wat-pathum-wanaram/

## หน้าในเว็บไซต์

- [หน้าแรก](https://6830051921-svg.github.io/wat-pathum-wanaram/) ประวัติวัดและแผนผังวัด
- [ศิลปะ](https://6830051921-svg.github.io/wat-pathum-wanaram/art.html) สถาปัตยกรรม จิตรกรรม และประติมากรรม
- [สถานที่สำคัญ](https://6830051921-svg.github.io/wat-pathum-wanaram/places.html) อาคารและสถานที่ภายในวัด
- [ผู้จัดทำ](https://6830051921-svg.github.io/wat-pathum-wanaram/credits.html) รายชื่อผู้จัดทำและแหล่งข้อมูล
